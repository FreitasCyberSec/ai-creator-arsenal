# Content Factory Pipeline

Use this folder as the contract between generation and distribution.

## State machine

```text
draft
  -> review
  -> approved
  -> scheduled
  -> published
  -> archived
```

Nothing generated by AI should jump directly from generation to public posting without an approval state unless you explicitly decide to remove that gate later.

## Recommended asset flow

```text
Character reference
  -> ComfyUI workflow
  -> image/video candidate batch
  -> quality filter
  -> human approval
  -> approved asset storage
  -> caption variants
  -> platform-specific adaptation
  -> scheduler
  -> publish
  -> collect metrics
  -> feed performance data back into next content batch
```

## Asset metadata

Store at minimum:

- `creator_id`
- `asset_id`
- type: image/video/audio
- source workflow
- seed / generation parameters
- prompt version
- face/identity reference version
- approval status
- consent/rights reference
- target platforms
- campaign
- published URLs
- performance metrics

## Quality gates

For character consistency, review:

- face geometry / identity
- hands and anatomy
- hair and eye consistency
- age presentation clearly adult
- background artifacts
- text/logos/watermarks
- temporal consistency in video
- lip sync if voice is used
- platform policy compatibility

## Platform split

Keep mainstream acquisition assets platform-safe. Adult-only material belongs only on services and surfaces that explicitly allow it.
